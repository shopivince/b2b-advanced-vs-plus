# Shopify B2B: Advanced vs Plus

A side-by-side comparison of B2B features available on Shopify Advanced versus Shopify Plus, plus the broader Plus-only capabilities (checkout customizations, custom apps with Functions, API limits, expansion stores, and more).

**Live site:** https://shopivince.github.io/b2b-advanced-vs-plus/

## What's in here

- B2B feature parity table (Companies, catalogs, payment terms, deposits…)
- Plus-only features beyond B2B (checkout customizations, Functions, expansion stores…)
- Checkout customizations & Shopify Functions — what's actually available on each plan
- Plus-only API restrictions to watch for
- Five key questions to ask before recommending a plan

## Disclaimer

This is **not** official Shopify documentation. Information is based on publicly available sources at the time of writing and may change. Always verify with [shopify.com/pricing](https://www.shopify.com/pricing), [help.shopify.com](https://help.shopify.com), or your Shopify representative before making purchasing decisions.
